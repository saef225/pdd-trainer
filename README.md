# Тренажёр билетов ПДД (A, B) — 40 билетов × 20 = 800 вопросов

## Сайт
https://saef225.github.io/pdd-trainer/

## Запуск локально
Просто откройте `index.html` двойным кликом — сервер не нужен.
Чтобы открывать с телефона, выложите папку целиком на любой статический хостинг (GitHub Pages, Netlify и т.п.).

## Режимы
- **Билет 1–40** — плитки краснеют/зеленеют по последнему результату (сдан = не больше 2 ошибок).
- **Экзамен** — 20 вопросов из разных билетов.
- **Марафон** — все 800; можно остановиться в любой момент, следующий марафон продолжит с непройденных.
- **Работа над ошибками** — только вопросы, где вы ошибались (вопрос уходит из списка после верного ответа).
- **По темам** и **поиск по всем 800 вопросам** (по тексту, ответам, пояснениям, номерам пунктов ПДД).

Незавершённая попытка переживает перезагрузку страницы.

## Google Таблица
По умолчанию все результаты пишутся в одну общую таблицу (URL в `config.js`). Каждый пользователь при первом входе указывает имя.
Свою таблицу можно подключить в «Настройках» — инструкция: `google-apps-script/ИНСТРУКЦИЯ.md`. Каждая попытка пишется
в листы «Попытки» и «Ошибки» (вопрос, ваш ответ, правильный, пояснение), плюс сводка «Частые ошибки»
и меню **ПДД** в таблице для выгрузки текста в чат и поиска.
Если интернета нет — попытка встаёт в очередь и уйдёт при следующем открытии сайта.

На странице результата есть кнопка **«Скопировать для чата»** — готовый текст без таблицы.

## Данные
Вопросы, картинки и пояснения — из открытой базы https://github.com/etspring/pdd_russia
